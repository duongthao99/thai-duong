Cách Chạy Thử & Tải Nhiều Ảnh Lên Thư Viện

  1. Chạy thử ngay: Toàn bộ chức năng đã hoạt động trực tiếp trên giao diện này hoặc mở file index.html bằng bất kỳ trình duyệt nào.
  2. Đăng nhập Quản trị: Nhấn nút "Quản Trị Viên" ở góc phải trên cùng (Mật khẩu mặc định: thaiduong2026).
  3. Tải nhiều ảnh cùng lúc: Nhấn "Thêm / Tải Nhiều Ảnh Mới", kéo thả 1 hoặc nhiều ảnh từ máy tính/điện thoại, hoặc dán URL ảnh từ Cloud. Hệ thống tự động nhận diện tỷ lệ 16:9, 9:16, 1:1, 3:4 và tạo bản thu nhỏ tối ưu tốc độ.
  4. Điền thông tin: Đặt tên tác phẩm, viết lời bình nghệ thuật, gắn từ khóa, chọn chủ đề, ngày sáng tạo và quyền cho phép tải ảnh gốc.

Đưa Lên GitHub Pages & Gắn Tên Miền Riêng

  1. Đưa lên GitHub Pages: Tạo một Repository mới trên GitHub (ví dụ thu-vien-thai-duong), tải các file trong gói mã nguồn lên. Vào Settings → Pages → Branch: main và nhấn Save.
  2. Kết nối Lưu trữ Đám mây: Tạo tài khoản miễn phí tại cloudinary.com, vào Settings → Upload → Add upload preset (chọn Signing Mode: Unsigned) rồi điền vào tab Cấu Hình Lưu Trữ Đám Mây trong trang Quản trị.
  3. Gắn tên miền riêng (ví dụ `thuvienthaiduong.vn`): Tại trang quản lý DNS tên miền (Tenten, Mắt Bão, Nhân Hòa, Cloudflare), tạo 4 bản ghi A trỏ về IP GitHub Pages (185.199.108.153, .109.153, .110.153, .111.153) và bản ghi CNAME www trỏ về <username>.github.io. Tích chọn Enforce HTTPS trong GitHub Pages.
