# THƯ VIỆN HÌNH ẢNH THÁI DƯƠNG — Thương Hiệu THÁI DƯƠNG

Không gian triển lãm, lưu trữ đám mây và quản trị tác phẩm nghệ thuật sáng tạo bằng Trí Tuệ Nhân Tạo (AI Art Gallery & Cloud Archive).

## 1. Cấu trúc thư mục
- `index.html`: Trang giao diện chính chuẩn SEO, OpenGraph, Schema.org ArtGallery.
- `assets/css/style.css`: Giao diện Museum Luxury (Sảnh Tối Obsidian & Sảnh Sáng Ivory).
- `assets/js/app.js`: Hệ thống hiển thị đa tỷ lệ (16:9, 9:16, 1:1, 3:4), tìm kiếm, lọc 9 chủ đề, Lightbox phóng to, Quản trị viên & Kết nối Cloudinary + GitHub API.
- `assets/images/`: Thư mục chứa ảnh bìa và tác phẩm minh họa ban đầu.
- `data/gallery.json`: Cơ sở dữ liệu danh mục tác phẩm lưu trữ bền vững.
- `CNAME`: Cấu hình tên miền riêng trên GitHub Pages.

## 2. Tài khoản Quản trị mặc định
- Nhấn nút **Quản Trị Viên** trên thanh điều hướng.
- Mật khẩu mặc định: `thaiduong2026` (Có thể đổi ngay trong tab Bảo mật).
